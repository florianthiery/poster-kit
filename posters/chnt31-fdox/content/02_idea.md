**FDOx** is a practice-driven, Linked-Data-based implementation of the FAIR Digital Object idea (De Smedt et al., 2020) for 3D cultural heritage: one model, one self-describing package (Thiery, 2026). All components are open source and deterministic, so anyone can repeat the workflow for their own models.

*Our own perspective, not an official FDO reference implementation.*
