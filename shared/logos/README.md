# Shared logos

Logos that several posters use (your institute, funders, networks) live here, once. Reference them from any
poster as `shared/logos/<file>`; a file of the same path inside a poster folder takes precedence.

The `example-*.svg` files are invented placeholders without any rights attached. Real logos carry the rights
of their owners: check the usage terms before you commit them to a public repository, and keep the
`source:` / licence note next to each file in the table below.

| File | What | Source and terms |
|---|---|---|
| `example-logo.svg`, `example-funder.svg`, `example-network.svg`, `example-institute.svg` | Placeholders | Generated for this template, no rights |
